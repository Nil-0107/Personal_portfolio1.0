# Personal Portfolio 1.0

A modern, single-page personal portfolio showcasing projects, skills, and contact links with polished interactive effects.

## Live Demo

https://personal-portfolio1-0-tawny.vercel.app/

## Features

- Hero section with availability badge and quick links
- About, projects, skills, and contact sections
- Theme toggle with persisted preference
- Magnetic text effect and cursor glow interaction
- Horizontal project showcase with scroll-based motion
- Interactive skill cards with detail panel

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.

Optional: run a simple local server (recommended for correct asset loading).

```bash
python -m http.server
```

Then visit `http://localhost:8000`.
